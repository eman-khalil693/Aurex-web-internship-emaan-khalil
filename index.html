1. CSS3 Core Concepts & Box Model

The CSS Box Model consists of content, padding, border and margin. These properties control the size and spacing of HTML elements.

Content Area

Padding + Border + Margin

Content

The actual text or element inside the box.

Padding

Space between content and border.

Border

The line around the element.

Margin

Space outside the element.
